Zero-Knowledge Vault with Sharing

Household vault items are encrypted with a DEK. Each user derives a KEK from their master password and gets a wrapped copy of the DEK. Sharing = wrapping the same DEK for another user — the backend never sees the plaintext DEK or vault data.

2 · Create Vault Item (User 1)

3 · Share with User 2
User 1 locally unwraps the DEK with their KEK, then re-wraps it with User 2's KEK and sends only the wrapped DEK to the backend.

Backend ends up with two wrapped DEKs for the same vault item: one for User 1 and one for User 2.

4 · User 2 Accesses Shared Vault Item

User 2 fetches only ciphertexts from the backend: encryptedData and their wrappedDEK. They derive KEK2 from their password, unwrap the DEK, then decrypt the vault item.
